# Фикстуры (dev / нагрузочные демо)

Сиды для observability: неравномерный граф подписок и вовлечённости,
чтобы в Grafana был реалистичный skew, а не «плоские» средние.

## Загрузка

```bash
# из корня проекта или внутри контейнера приложения
php bin/console doctrine:fixtures:load --no-interaction
```

Docker:

```bash
docker compose exec frankenphp php bin/console doctrine:fixtures:load --no-interaction
```

Команда **очищает** таблицы и загружает заново:

| Фикстура         | Объём             | Что внутри                                                                                                                                                                                  |
|------------------|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `UserFixtures`   | 400 пользователей | Пароль у всех: `password` (хеш один раз). Первые 10 — инфлюенсеры (`influencer_0`…`influencer_9`). Логины вида `user_N` / `user_N@example.com`.                                             |
| `TweetFixtures`  | 4000 твитов       | ~60% твитов у ~20% авторов (weighted random). Текст — через Faker `realText`.                                                                                                               |
| `FollowFixtures` | ~20000 follow     | Инфлюенсеры: много фолловеров (`random_int(100, 5000)`, упирается в число уникальных юзеров); обычные: мало исходящих (`0…50`); остаток — пары с уклоном к инфлюенсерам. DBAL batch insert. |
| `LikeFixtures`   | ~30000 лайков     | Zipf-подобное распределение по твитам; затем пересчёт `tweets.likes_count`. DBAL batch insert.                                                                                              |

## Зачем неравномерность?

Равномерный рандом даёт скучные плоские метрики. Степенные / weighted распределения делают графики осмысленными:

- **Горячие авторы / инфлюенсеры** — всплески объёма твитов, follow и fan-out lag.
- **Вирусные твиты** — перекос `likes_total`, нагрузка на feed projection, hit rate кэша.
- **Long-tail пользователи** — контраст с инфлюенсерами на панелях active users и rate limit.

Так ближе к продакшен-соцграфу — и ради этого в лабе крутится Grafana.

## Логин после загрузки

```text
email:    user_0@example.com   (инфлюенсер)
password: password
```

Подойдёт любой `user_{N}@example.com` / `password` (`N` = 0…399).

## Что даёт Faker

| Поле             | Источник                                    |
|------------------|---------------------------------------------|
| username / email | Детерминированные строки `user_N`, не Faker |
| текст твита      | Faker `realText` (английский «живой» текст) |
| даты             | Faker `dateTimeBetween`                     |
